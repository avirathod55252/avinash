# Avinash Rathod - Resume (React + Tailwind)

This is a single-page resume website built with React and Tailwind CSS.
Light theme, includes your uploaded profile image (blurred for privacy).

## How to run

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start dev server:
   ```bash
   npm start
   ```

Notes:

- Tailwind setup included in devDependencies; run `npm install` to get them.
- If using create-react-app, ensure environment supports PostCSS/Tailwind.
